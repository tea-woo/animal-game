# 🦁 야생의 왕좌 · Wild Throne

사자 · 늑대 · 곰 · 아나콘다로 변신해 사바나 아레나에서 싸우는 **3D 동물 액션 게임**입니다.
빌드 과정 없이 브라우저에서 바로 실행되며, PC(키보드/마우스)와 아이폰(터치) 모두 지원합니다.

> **바로 플레이:** https://tea-woo.github.io/animal-game/

---

## 플레이 방법

1. 시작 화면에서 원하는 동물 카드를 눌러 **스폰**합니다.
2. 아레나를 돌아다니는 멧돼지 무리를 사냥하세요. 처치한 적은 일정 시간 뒤 다시 나타납니다.
3. 스킬은 쿨다운이 있습니다. 기력(Stamina)을 쓰면 질주할 수 있으니, 기력을 관리하며 싸우세요.
4. `동물 변경`(Esc) 버튼으로 언제든 다른 동물로 갈아탈 수 있습니다.

### 조작

| 동작 | PC | 모바일 |
| --- | --- | --- |
| 이동 | `W A S D` / 방향키 | 왼쪽 조이스틱 |
| 질주 | `Shift` (기력 소모) | `질주` 버튼 (누르고 있기) |
| 점프 | `Space` | `점프` |
| 기본 공격 | `J` 또는 마우스 클릭 | `공격` |
| 스킬 1 | `K` / `1` | 스킬 버튼 1 |
| 스킬 2 | `L` / `2` | 스킬 버튼 2 |
| 시점 | 마우스 드래그 · 휠 줌 | 화면 드래그 |

## 동물 소개

각 동물은 실제 생물의 사냥 방식에 맞춘 공격과 스킬을 가집니다.

### 🦁 사자 — 사바나의 제압자

| 키 | 기술 | 설명 |
| --- | --- | --- |
| `J` | **앞발 할퀴기** | 몸을 틀어 앞발을 크게 휘두르는 넓은 범위 참격 |
| `K` | **사자의 포효** | 충격파로 주변 적을 밀쳐내고 1.8초 기절 |
| `L` | **맹수의 도약** | 앞으로 길게 도약해 착지 지점을 강타 |

### 🐺 늑대 — 달빛의 추격자

| 키 | 기술 | 설명 |
| --- | --- | --- |
| `J` | **송곳니 물기** | 짧게 파고들어 목덜미를 무는 빠른 공격 |
| `K` | **달빛 질주** | 달빛 잔상을 남기며 돌진해 지나치는 적을 베어냄 |
| `L` | **무리 울부짖기** | 9초 동안 이동 속도·공격력 35% 증가 |

### 🐻 곰 — 대지의 분노

| 키 | 기술 | 설명 |
| --- | --- | --- |
| `J` | **묵직한 내리치기** | 두 앞발로 내려찍는 강력한 광범위 공격 |
| `K` | **대지 강타** | 땅을 내리쳐 반경 8m 충격파 + 기절 |
| `L` | **광폭 돌진** | 앞으로 미친 듯이 돌진해 부딪히는 적을 날려버림 |

### 🐍 아나콘다 — 수풀의 포식자

| 키 | 기술 | 설명 |
| --- | --- | --- |
| `J` | **기습 물기** | 물 밖으로 솟구치듯 머리를 날카롭게 내지르는 기습 |
| `K` | **압박하기** | 가까운 적에게 파고들어 몸으로 조여 옥죄며 2초 동안 지속 피해. 대상은 움직이지 못합니다 |
| `L` | **꼬리 강타** | 꼬리를 크게 휘둘러 주변 적을 강하게 밀쳐냄 |

## 기술 스택

- **Three.js r169** (ES 모듈, CDN 로드 + 다중 CDN 폴백) — 빌드 도구 없음
- 순수 HTML / CSS / JavaScript (모듈)
- 모든 그래픽은 **절차적(procedural)** 생성: 외부 3D 모델·텍스처 파일 없음
- 사운드는 **WebAudio 합성** (오디오 파일 없음)

### 구현 포인트

- **관절 애니메이션**: 몸통·목·머리·턱·귀·꼬리·4개 다리의 관절 계층을 절차적으로 회전시켜
  대기(호흡·꼬리 흔들기) / 걷기 / 질주(갈롭) / 점프 / 공격 / 스킬 자세를 실시간 블렌딩합니다.
- **뱀 전용 리그**: 14개 마디의 관절 체인에 위상차 사인파를 주어 S자 물결 이동을 만들고,
  질주할수록 파형이 빨라집니다.
- **전투**: 부채꼴 판정(기본 공격), 원형 범위 판정(스킬), 넉백, 기절, 지속 피해(조이기),
  콤보 카운터, 피해 숫자, 화면 흔들림.
- **적 AI**: 순찰 → 인지 → 추격 → 예비동작(telegraph) → 돌진 공격 → 후딜레이, 그리고 사망·부활.
- **성능**: 모바일에서는 그림자 맵·픽셀 비율·개체 수를 낮추고, 프레임이 떨어지면 자동으로 해상도를 조정합니다.

## 로컬에서 실행

ES 모듈을 사용하므로 `file://`이 아니라 **로컬 서버**로 열어야 합니다.

```bash
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

## 검증

브라우저 콘솔에서 자체 점검을 실행할 수 있습니다.

```js
await window.__game.runSelfTest()
// 각 동물의 이동/질주/점프/공격/스킬 판정과 피해량을 확인해 결과를 돌려줍니다.
```
