# 야생의 왕좌 · Wild Throne

사자부터 범고래까지, 네 가지 지형에서 벌어지는 3D 동물 액션 게임.
Three.js 하나로 만든 무빌드 정적 사이트입니다. → <https://tea-woo.github.io/animal-game/>

## 이번 업데이트

### 🗺 지도(맵) 메뉴 — 4가지 무대
시작 화면의 **지도 선택**과 게임 중 HUD의 **🗺 지도** 버튼으로 언제든 지형을 바꿀 수 있습니다.
페이지를 새로고침하지 않고 무대만 교체되며, 마지막 선택은 브라우저에 기억됩니다.

| 지도 | 분위기 | 야생 AI |
| --- | --- | --- |
| 🌾 사바나 | 황금빛 마른 풀, 아카시아, 붉은 흙, 따뜻한 햇살 | 얼룩말 · 하이에나 · 혹멧돼지 |
| 🌊 바다 | 파도와 거품, 산호초, 야자수, 시원한 빛 | 바다거북 · 가오리 · 청새치 |
| 🌲 숲 | 빽빽한 나무와 이끼, 쓰러진 통나무, 스며드는 빛 | 멧돼지 · 사슴 · 붉은여우 |
| ❄️ 설원 | 눈보라, 눈 덮인 소나무, 얼음 결정, 푸른 빛 | 순록 · 북극여우 |

지형마다 바닥 재질·식생·안개·조명·원경이 모두 바뀌고, 먼 지평선은 겹친 능선과 안개로
가려져 잘린 종이 같은 경계가 보이지 않습니다. AI는 지형당 **4~6마리**만 서로 떨어져 등장합니다.

### 🐾 동물 12종 (지형 추천 표시, 어디서나 선택 가능)
| 지형 | 동물 |
| --- | --- |
| 사바나 | 사자 🦁 · 아프리카 코끼리 🐘 · 치타 🐆 · 코뿔소 🦏 |
| 바다 | 백상아리 🦈 · 범고래 🐋 · 대왕문어 🐙 |
| 숲 | 늑대 🐺 · 곰 🐻 · 아나콘다 🐍 · 호랑이 🐯 |
| 설원 | 북극곰 🐻‍❄️ (늑대도 추천) |

모든 동물은 기본 공격 + 스킬 2개를 가집니다.
예) 백상아리 — 턱 물기 / 혈흔 돌진 / 꼬리지느러미 강타,
범고래 — 몸통 박치기 / 브리칭 강타 / 초음파 파동,
대왕문어 — 촉수 채찍 / 먹물 분사 / 8다리 휘감기,
코끼리 — 코 후려치기 / 상아 돌진 / 대지 발구르기.

### 🧶 털 · 비늘 재질
- 사자·늑대·곰·호랑이·치타·북극곰 등은 **방향성 털가닥 텍스처**(map)와
  **울퉁불퉁한 털 결(bumpMap)**, 거칠기 변화(roughnessMap)를 함께 사용합니다.
  갈기·목덜미·꼬리에는 실루엣을 푸는 털뭉치를 덧대 입체감을 살렸습니다.
- 아나콘다는 광택 나는 비늘 텍스처(등면 검은 반점, 옆구리 주황 타원, 크림 배)와
  낮은 거칠기로 젖은 파충류 광택을 냅니다.
- 텍스처는 동물별 256×256 캔버스로 한 번만 생성해 캐시합니다(모바일 부담 최소화).

### 🧱 모델링
몸통·목·다리·꼬리를 스윕(sweep) 튜브와 병합 지오메트리로 다시 만들어
이음매가 보이지 않고 실루엣이 동물답게 읽히도록 했습니다.
털뭉치·발톱·이빨처럼 작은 부품은 한 지오메트리로 합쳐 드로우콜을 줄였습니다.

## 조작
- **PC**: WASD/방향키 이동 · Shift 질주 · Space 점프 · J 공격 · K/L 스킬 · 마우스 드래그 시점 · Esc 동물 변경
- **모바일**: 왼쪽 조이스틱, 오른쪽 버튼(질주·점프·공격·스킬2)

## 구조
```
index.html        화면 · HUD · 지도/동물 선택 마크업
style.css         UI 스타일
src/world.js      지도 4종 생성(지형·식생·물·안개·원경)
src/animals.js    동물 12종 + 지형별 AI 모델
src/sculpt.js     스윕/병합/털 조형 도구
src/textures.js   털·비늘 절차적 텍스처
src/player.js     이동·공격·스킬 상태 머신
src/enemies.js    지형별 AI 매니저
src/ui.js         메뉴 · HUD
```

## 검증
`window.__game.runSelfTest()`로 12종 스폰·이동·질주·점프·공격·스킬과
지도 4종 로드/이동을 자동 점검합니다. 콘솔 오류 0건.
